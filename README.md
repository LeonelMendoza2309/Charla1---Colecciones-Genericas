</div>

## Descripción del proyecto

Este repositorio contiene ejemplos prácticos sobre **Colecciones Genéricas en C#**, abarcando diferentes escenarios de uso y manejo de excepciones. Los proyectos demuestran cómo utilizar estructuras de datos genéricas como `List<T>`, `Dictionary<K, V>` y otras colecciones disponibles en el .NET Framework.

---

## Estructura del proyecto

```text
Charla1---Colecciones-Genericas/
├── Escenario#1 - Charla#1/         # Introducción a colecciones genéricas
├── Escenario 2 - ErrorCatcher/         # Manejo de excepciones con try-catch
├── Escenario #3/                   # Escenario avanzado
└── README.md                        # Documentación del repositorio
```

### Escenarios incluidos

1. **Escenario #1 - Charla #1**: Fundamentos de colecciones genéricas y su utilización básica en C#.
2. **Escenario 2 - ErrorCatcher**: Manejo robusto de excepciones aplicadas a operaciones con colecciones.
3. **Escenario #3**: Casos de uso avanzados y aplicaciones prácticas.

### Abrir el proyecto

1. Iniciar Visual Studio.

4. Compilar la solución.
5. Ejecutar el programa.

## Contenido de cada escenario

### Escenario #1 - Charla #1
Introduce los conceptos básicos de colecciones genéricas:
- Uso de `List<T>`
- Operaciones básicas (agregar, eliminar, buscar)
- Iteración sobre colecciones
- Ventajas de las colecciones genéricas

### Escenario 2 - ErrorCatcher
Demuestra el manejo robusto de excepciones:
- Bloques `try-catch` en operaciones con colecciones
- Manejo de excepciones específicas
- Limpieza de recursos con `finally`
- Prevención de errores en tiempo de ejecución

### Escenario #3
Casos de uso avanzados:
- Colecciones más complejas
- Operaciones LINQ
- Patrones de diseño aplicados

---

## Conceptos clave

- **Colecciones Genéricas**: Estructuras de datos type-safe en C#.
- **List<T>**: Colección genérica ordenada y redimensionable.
- **Dictionary<K, V>**: Colección de pares clave-valor.
- **Manejo de Excepciones**: Uso de try-catch para capturar errores.
- **LINQ**: Consultas sobre colecciones de forma funcional.
